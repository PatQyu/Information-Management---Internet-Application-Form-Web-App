# Internet-Application-Form-Web-App

> **A DB in fulfillment of the requirements in the Information Management course (BSCS 2-2) at the Polytechnic University of the Philippines (PUP).**

A web-app focused on simulating an internet service provider's (ISP) application process. This project demonstrates the practical application of database management, featuring a fully functional CRUD (Create, Read, Update, Delete) interface to handle customer service applications efficiently.

---

## Tech Stack 
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Flask
- **Version Control:** Git & GitHub
